Konta System Kya Kaam Karta Hai? (Subsystem Breakdown)

📡 1. Ingestion Layer (Message Collector)

Ye layer external duniya se raw messages ko capture karti hai. Chahe user ke Android phone par SMS aaye, WhatsApp notification pop ho, ya browser par WhatsApp Web open ho—ye components us message ko securely pakad kar backend API ko bhejte hain.

🧠 2. AI Detection Engine (Brain)

Backend service (`detector.py`) jo incoming text ko analyze karti hai. Ye message ke andar urgency words, bank fraud patterns, PAN card extortion, aur fake URLs ko check karke 0 se 100 ka Risk Score calculate karti hai.

🛡️ 3. Policy & Quarantine Subsystem

Agar Risk Score 75 se zyada ya level CRITICAL hota hai, toh ye system automatically `is_red_flagged = True` set karta hai, action ko QUARANTINE_AND_NOTIFY banata hai aur SQLite DB me store karta hai.

💻 4. SOC Frontend Dashboard & Auth

Security Officer ke samne chalne wala web console. Ye WebSockets ke through bina page refresh kiye incoming threats dikhata hai, warning sound bajata hai, aur analyst ko login/signup access control deta hai.

💡 Key Architecture Philosophy

System ko is tarah design kiya gaya hai ki agar ML model pre-trained file load na bhi ho, tab bhi heuristic domain-specific rules fallback ke taur par 100% scam detection accuracy maintain rakhte hain.

THREATGUARD AI Section 3: AI Detection Logic

3. AI Kaise Kaam Karta Hai? (Under the Hood)

AI kisi bhi incoming message ko 4 sequential stages me process karta hai:

Stage 1: Preprocessing & URL Parsing Message text ko clean kiya jata hai aur regular expressions ke through usme maujood sabhi web links (`http://`, `https://`, ya raw domains) ko extract kiya jata hai.
Stage 2: Heuristic Cyber-Threat Weighting AI text ke andar specialized cyber-fraud patterns ko scan karke points add karta hai:
Fraud Category Detection Patterns & Keywords Risk Weight Real Scam Example
1. Urgency Coercion `immediately`, `within 24 hours`, `account suspended`, `electricity cutoff tonight` +25 to +35 pts "Your power supply will be disconnected at 9:30 PM due to unpaid bill. Call immediately."
2. Credential Theft `update pan`, `kyc pending`, `enter otp`, `card blocked`, `sbi-yono` +35 to +45 pts "Dear SBI User, your YONO account is locked. Submit your PAN here: http://bit.ly/sbi-pan"
3. Fake Job / WFH Task `part-time job`, `earn 5000 daily`, `like youtube video`, `telegram contact`, `hotel rating` +50 pts "Earn ₹5000/day from home by rating hotels on Google Maps. Send message to @HR_Recruiter."
4. Lookalike & Short URLs `bit.ly`, `tinyurl`, `.xyz`, `.top`, `.tk`, raw IP address links +35 to +40 pts "Link: http://192.168.1.10/login or http://sbi-verification.xyz"

Risk Score Calculation & Red-Flagging Formula

Total Risk Score compute hone ke baad system automatic decision leta hai:

Risk Score = Min(100, Base_NLP_Probability * 50 + Sum(Heuristic_Category_Weights)) IF (Risk Score >= 75 OR Risk Level == "CRITICAL"): is_red_flagged = True action_taken = "QUARANTINE_AND_NOTIFY" alert_badge = "🚨 RED FLAGGED" Play_Audio_Siren() ELSE IF (Risk Score >= 50): is_red_flagged = False action_taken = "FLAG_FOR_REVIEW" alert_badge = "⚠️ HIGH RISK" ELSE: is_red_flagged = False action_taken = "ALLOW" alert_badge = "✅ SAFE"

🚨 Red Flag Action Policy

Jab bhi `is_red_flagged` True hota hai, message ko dashboard ki Quarantine Table me permanently log kiya jata hai aur Web Audio API browser par ek 880Hz alternating frequency siren chime trigger karta hai taaki security analyst ka turant dhyan jaye.

THREATGUARD AI Section 4: Data Flow Scenarios

4. WhatsApp & SMS Ka Message Kaise Aata Hai?

Ek practical example se samjhiye ki real life me message aane par system me kya-kya hota hai:

Scenario A: WhatsApp Par Scam Message Aaya

Step 1: User ke Phone ya WhatsApp Web par Message Aaya Scammer ne number `+91 91234 56789` se bheja: "Earn ₹5,000/day by liking YouTube videos! Join Telegram t.me/task99".
Step 2: Message Interception (Mobile / Web) Mobile Par: Android ki `ThreatGuardNotificationReceiver.kt` WhatsApp ki notification read kar leti hai.
Web Par: Chrome extension ka `content.js` WhatsApp Web ki chat DOM me se text aur link grab kar leta hai.
Step 3: Backend Ingestion API Trigger Listener background me POST request fire karta hai:
POST http://127.0.0.1:8000/api/whatsapp/incoming Headers: {"Content-Type": "application/json"} Body: { "sender": "+91 91234 56789", "channel": "whatsapp", "message": "Earn ₹5,000/day by liking YouTube videos! Join Telegram t.me/task99" }
Step 4: AI Analysis & DB Commit `detector.py` message ko scan karta hai: WFH pattern (+50) + Telegram redirection (+35) = Risk Score 85 (CRITICAL). Message `is_red_flagged: True` ke sath `threatguard.db` me save hota hai.
Step 5: WebSocket Real-Time Broadcast Backend `/ws/sms` par connected sabhi active browsers ko live alert packet broadcast karta hai.
Step 6: Dashboard Action (Instant Warning) Dashboard par bina page refresh kiye:
  • Flashing Red Alert Siren banner pop-up hota hai.
  • Sound alert (Chime) bajta hai.
  • Red-Flag Counter badge 1 se badh jata hai.
  • Quarantine table me threat breakdown reasons display ho jate hain.

Scenario B: User Authentication Flow (Login & Signup)

📝 Registration (`POST /api/auth/register`)

User apna Naam, Email aur Password deta hai. Backend 16-byte random salt generate karke `hashlib.pbkdf2_hmac('sha256')` se 100,000 iterations me secure hash banata hai aur `users` table me store karta hai.

🔑 Login (`POST /api/auth/login`)

Email se user record fetch hota hai. Saved salt ke sath input password ko re-hash karke verify kiya jata hai. Success par session token aur user profile return hota hai jo browser ke `localStorage` me save ho jata hai.

THREATGUARD AI Section 5: API Docs & Deployment

5. REST API Reference & Operational Guide

Method Endpoint Description Sample Payload / Params
POST `/api/sms/incoming` SMS message ingestion & real-time red-flag analysis. `{"message": "...", "sender": "+91...", "channel": "sms"}`
POST `/api/whatsapp/incoming` WhatsApp message ingestion & threat detection. `{"message": "...", "sender": "+91...", "channel": "whatsapp"}`
GET `/api/sms/live-feed` Returns total SMS scanned, red-flag count & recent history. Query: `?limit=20`
POST `/api/sms/simulate` One-click simulation of pre-configured scams & safe texts. `{"preset_key": "pan_deactivation"}`
POST `/api/auth/register` Registers a new SOC analyst user in the database. `{"full_name": "...", "email": "...", "password": "..."}`
POST `/api/auth/login` Authenticates credentials and returns session token. `{"email": "...", "password": "..."}`
GET `/api/auth/me` Fetches currently logged-in analyst's profile. Header: `Authorization: Bearer `
WS `/ws/sms` WebSocket stream for real-time live threat broadcasting. Duplex event stream
